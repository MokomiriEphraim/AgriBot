# AgriBot 

AgriBot is an AI-powered agricultural assistant designed to help farmers with crop-related questions and plant health issues.

Users can ask farming questions, upload crop images for analysis, receive practical agricultural guidance, and get a 14-day crop prognosis.

## Features

- AI-powered agricultural chatbot
- Crop and plant image analysis
- Crop health and disease guidance
- Pest and disease advice
- Irrigation and soil-related guidance
- Weather and farming advice
- 14-day crop prognosis
- Conversation history
- Mobile-friendly interface

## Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **OpenAI API**
- **MongoDB**
- **Tailwind CSS**
- **React Markdown**

##Team
